# test-evidence-review

Read criteria, changed tests and supplied run records. For each criterion state
verified, incomplete or missing, with the evidence and remaining check.
Distinguish source formatting, place assembly, type analysis, runtime behavior,
multi-client replication and device testing. Check commit/place/mode freshness;
file presence does not prove execution. One meaningful assertion can be enough.
Do not require fictional department sign-offs or inspect unrelated live user data.
Review is read-only; do not close a story or publish from an evidence review.

For captures, inspect the meaningful actions and result, checking for black/frozen frames, obscured windows and stale state. A playable video file or successful ffprobe does not prove the scenario passed.
