# Start with Roblox Studio

Read [the workflow guide](../../docs/roblox-workflow.md).
Use `roblox-workflow` for setup, `dev-story` for a feature, `code-review`
for review, `roblox-test` for testing, `test-evidence-review` for proof,
and `roblox-release` for an explicitly requested release.
The inherited studio templates are optional; the active stack is Roblox/Luau.
