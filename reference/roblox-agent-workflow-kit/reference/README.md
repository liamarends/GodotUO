# Read-only GUO examples

Start with scenario_run/README.md (scenario contracts), scenario.py (validation), driver.py and uiquery.py
(actions and observations), capture.py (recording lifecycle), events.py (evidence), and redact.py (privacy).
The schema folder shows structured runs and events. The launcher files show exit-code propagation and checks.
The QA roles/skills provide test planning, defect reporting and evidence review examples.

These are selected files, not a runnable checkout. Dependencies were deliberately not bundled.
The original README includes planned features and old paths: prefer this kit's adaptation guides for Roblox.
Do not execute these launchers, enroll in the original fleet, use its machine paths, or adopt its model defaults.
Source attribution and applicable licenses are preserved. No GUO game assets are included.
