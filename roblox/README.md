# Roblox Studio starter

Minimal server/client/shared Luau workspace for the adapted development workflow.
No existing experience, economy, datastore or UO gameplay is included.

See [workflow and Studio test instructions](../docs/roblox-workflow.md).
Build from the repository root:
`rojo build roblox/default.project.json -o build/roblox-starter.rbxlx`
after creating build/. Open the output in Studio and test.

Rojo source is authoritative for mapped script folders. Studio is used to edit
scene assets; save/back up those separately before rebuilding a place.
