# Standalone Meta Quest version of kai's mayu

## One listing, two builds

VRChat uses its Android target for standalone Meta Quest. The existing private avatar has a Windows package and a separate slot for its Quest package. Keep the fitted avatar's Pipeline Manager blueprint ID in both scenes. Verify the owner, name and private visibility before updating. After upload, fetch the listing again and check that the platform list includes `standalonewindows` and `android`. A local SDK build or a reserved ID alone does not confirm that the Quest upload succeeded. [VRChat cross-platform setup](https://creators.vrchat.com/platforms/android/cross-platform-setup/)

## Preparing the Quest scene

The Windows update is based on `Assets/Mayu Blue - Wheel Fitted.unity`. The Quest scene is `Assets/Kai Quest/Kai Mayu Quest.unity`. Use Unity 2022.3.22f1 with Android Build Support. The Android module in this setup came from the matching Unity release manifest. Its checksum and Authenticode signature were checked before installation. [VRCQuestTools environment tutorial](https://kurotu.github.io/VRCQuestTools/docs/tutorial/set-up-environment/)

* Start from the same fitted scene so objects and menu controls have the same names. Keep Emo Hair first in Expressions and the two garments in Clothes. Compare the final network-synchronized parameter names, types and order on both platforms. This project produced 144 matching synchronized parameters in the two examined builds.
* Reduce meshes with meshoptimizer while retaining the selected vertices' UVs, skin weights and blendshape deltas. Leave the hair's gradient vertex colors in place. The full wearable set, including disabled wearable meshes, totaled 25,506 triangles after reduction. The many independently switchable renderers and materials carry a performance cost. [meshoptimizer simplification](https://github.com/zeux/meshoptimizer#simplification) · [VRChat performance ranks](https://creators.vrchat.com/avatars/avatar-performance-ranking-system/)
* Use VRCQuestTools 3.0.2 with NDMF for material conversion. The creator's conversion tutorial covers adding the converter, configuring materials and building for the other platform. Quest only supports VRChat's mobile shaders. A PC-only shader effect or audio source cannot be assumed to transfer with a menu label. [Creator's conversion tutorial](https://github.com/kurotu/VRCQuestTools/blob/master/Website/docs/getting-started/convert-avatar.md) · [Android content limitations](https://creators.vrchat.com/platforms/android/quest-content-limitations/)
* For the pants and cyber limbs, split the underlying body triangles using the coverage texture. The equip actions hide the corresponding body pieces. Nested gates handle overlap when two items are active. This provides coverage on Quest without using Poiyomi's PC alpha effects.
* Reuse the same Android ASTC body and head albedo maps across equivalent material variants. Enable **Streaming Mip Maps** on the mipmapped textures. The first bundle measured 7.1 MB compressed but 59.1 MB unpacked and exceeded the mobile unpacked limit. A later size check after deduplication measured about 4.3 MB compressed and 18.4 MB unpacked. Inspect both sizes, since either can block an upload. [VRChat avatar size limits](https://creators.vrchat.com/avatars/avatar-size-limits/)
* Keep selected physics rather than relying on the client to strip an over-budget category. The budget pass retained eight PhysBones, at most 27 affected transforms, three colliders, at most 23 collision checks and 16 contacts.

In a headset, wear the uploaded avatar and check the hair, shirt, pants, crouching, cyber limbs, and another user's view of the switches. Physics, audio, shader effects and interactive props can behave differently from the PC client. The SDK's ownership agreement is an account-holder step when it appears.
