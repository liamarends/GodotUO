# Preserved GodotUO configuration

This archive contains the inherited Godot/UO roles, skills, hooks, MCP configuration,
root instructions and GitHub workflows as they existed before Roblox adaptation.
They are not active: GitHub only runs workflows under the repository-root
.github/workflows directory, and active skill discovery uses .claude/skills.

Historical references in these snapshots use their original repository paths.
The original game source, tools and wiki documentation remain at those paths;
this archive is for reference, not a standalone build distribution.
Do not restore hooks, workflows or MCP entries merely to work on Roblox.

The active guide is [Roblox workflow](../../docs/roblox-workflow.md).
